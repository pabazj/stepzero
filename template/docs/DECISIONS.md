# Decisions

One line per decision, newest at the bottom. Format:
`YYYY-MM-DD: <decision>. <why>.`

To reverse a decision, add a new line that supersedes it. Never edit or
delete old lines. Agents append after the human approves; they don't rewrite.

- YYYY-MM-DD: Adopted the stepzero workflow (plan → build → check → review). Consistent, checkable process.
